策划方法入门 —— 五个工具，把"我想做游戏"变成"图纸"

| 为什么有这份文档 | 有了 `01_一个游戏的一生` 的全景，你知道策划是第 2 阶段、最重要的一步。但"怎么策划好"是有方法的——这份文档给你五个立刻能用的工具 |
|---|---|
| **不用这些方法会怎样** | GDD 模板也填了，但填出来的是空话（"玩法有趣、画面精美"）——第 6 站开工三天就露馅 |
| **是什么** | 五个策划工具：核心循环 / 一句话定位 / 范围切片 / 对标拆解 / 可判定验收 |
| **怎么用** | 通读一遍 → 策划自己的游戏时按顺序用一遍 → 填 GDD 模板时对照检查 |
| **什么时候用** | 第 5 站主任务；第 6 章每次"要不要加功能"犹豫时回来用工具 3 |

工具1：核心循环 —— 你的游戏每 5 分钟在重复什么

一切好玩的游戏，都有一个让玩家**想再来一轮**的循环：

```
玩（做核心动作）→ 得（获得反馈/奖励）→ 想（想再来一次/变强一点）→ 玩……
```

| 例 | 循环 |
|---|---|
| 接星星（第2站做的） | 移动接星星 → 得分、速度变快 → "这局我能接更多" → 再来 |
| 背包乱斗 | 打一局 → 拿到新物品、试新组合 → "下把组个更强的" → 再来 |

**怎么用**：用三个动词写出你游戏的循环（例：探索→拾取→解谜）。写不出三步闭环 = 玩法还没想清楚。
**自检**：玩家通关一局后，是什么念头让他点"再来一局"？这个念头就是你的循环成立与否。

工具2：一句话定位 —— "它像 X，但是 Y"

对你想做的游戏说：**"它像（某个具体游戏），但是（1 个差异点）。"**

- "像《背包乱斗》，但是塔防" ✓
- "像一个很好玩的养成游戏" ✗（没有参照，没法检验）

**为什么灵**：像谁 = 你有现成的拆解对象（玩法循环可以直接学）；但什么 = 你的游戏存在的理由（玩家为什么玩你的而不是原版）。

工具3：范围切片 —— 首版只验证一个小循环

新手最大的敌人不是"不会做"，是"想做太多"。规则：

| 层 | 意思 | 处理 |
|---|---|---|
| **P0** | 验证核心循环必需 | 首发就做这些 |
| **P1** | 完整版需要 | 切片验证好玩之后再做 |
| **P2** | 锦上添花 | **默认不做**，想加时先问："不做会死吗？" |

**判断练习**：P0取决于玩法假设。接星星可以用限时、漏接或其他结束条件；音乐在依赖节奏的玩法中可能必需。说明删掉该项后是否还能验证目标，不机械套用别人的优先级。
**砍功能不是损失，是保命**：先完成一个可验证的小循环，体验时长随玩法和课时确定。

工具4：对标拆解 —— 抄循环，不抄皮

选 1~2 个你**亲测玩过且喜欢**的同类游戏，让 AI 帮你拆：

```
对标拆解《___》：列出它的核心循环（动词级）、前 15 分钟玩家的体验节奏
（每分钟在干什么）、系统清单、美术风格关键词。
然后帮我写清楚：我抄它的什么（循环结构/节奏），不抄它的什么（题材/细节/体量）。
```

**铁律**：抄的是**结构和节奏**（为什么好玩），不抄**题材和内容**（它长什么样）。前者叫学习，后者叫复制。

工具5：可判定验收 —— 把形容词全部杀掉

GDD 里不许出现没法检验的词：

| ✗ 空话 | ✓ 可判定 |
|---|---|
| "玩法有趣" | "按钮能重开、状态归零；另观察试玩者是否理解并愿意继续" |
| "画面精美" | "16 像素风格，色板 8 色，主角 4 帧走路动画" |
| "内容丰富" | "首发 3 关，每关 1 个新机制" |

**为什么重要**：第 6 章里 AI 是照 GDD 施工的工人——图纸写"有趣"，工人就自由发挥；写"3 关每关 1 新机制"，工人才能验收交付。

五个工具怎么串起来（策划动线）

```
工具2 一句话定位（我是谁）
   → 工具1 核心循环（玩家为什么反复玩）
   → 工具4 对标拆解（向谁学、学什么）
   → 工具3 范围切片（首发只做多少）
   → 填 GDD 模板（用工具5 把每一条写成可判定的）
```

走完这条动线，你产出的就是一份能开工的 GDD——那份文档就是你游戏的宪法。

功能达标与体验有效分开记录

有重开按钮不能证明玩家想再玩，色板和帧数也不能证明画面合适。功能检查记录“是否按预期运行”；体验验证记录“玩家是否理解目标、在哪犹豫、为什么继续或退出”，不把少量同学意见泛化成所有玩家。

灰盒先验证一个玩法假设，垂直切片再检查一小段较完整体验与制作成本，二者不混为固定15分钟的交付。先做最小可观察版本，试玩后决定继续、修改或缩小。
