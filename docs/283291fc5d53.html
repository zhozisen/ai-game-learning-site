# 10 第1站·Git 时光机 —— 先读我

| 为什么有这一站 | 从今天起你就要让 AI 帮你干活了——AI 干活会犯错，而 git 是唯一能让错误**随时撤销**的时光机。保险绳必须在放手之前系上，所以它是第一站，不是选修课 |
|---|---|
| **跳过会怎样** | 之后每一站让 AI 改文件都是裸奔：AI 一抽风，你连它改了什么都不知道，更别说改回去；知识包的更新通道（git pull）也用不了 |
| **是什么** | 一份 45 分钟的入门课《给代码装一台时光机》：三个噩梦 → 为什么非学不可 → 七个核心概念（全用游戏常识讲）→ AI 时代怎么配合用 → 一张速记卡 |
| **怎么用** | 通读一遍讲义（45 分钟）→ 现场做完三件小事（30 分钟）→ 对照过站验收 |
| **什么时候用** | 进所有站之前；之后忘了任何概念，回本站查速记卡 |

## 为什么第一站学的是它，而不是 Godot

两个理由：

1. **它是安全网，网必须先张开**。这条路上 AI 从第一天就开始帮你写东西、改文件。让 AI 干活而没有 git，就像不带保险绳走钢丝——本站的时光机装好，后面每一站你都可以放心让 AI 折腾：改崩了，读档重来。
2. **它是最轻的一站**。不需要任何编程基础，不需要懂游戏引擎，一张速记卡就能上手——最适合当第一站建立"我学得会"的信心。

### 配套视频怎么用（选学）

如果只读文字还不够直观，可以配合上面的视频学习。优先围绕本站任务理解**本地仓库、提交、分区，以及本地与远程仓库的关系**；分支和多人协作等内容可按需要继续观看，不要求一次全部掌握。

观看时带着三个问题：

1. 修改一个文件后，怎样才算真正留下了一次提交记录？
2. 本地提交与把内容同步到 GitHub，各自解决什么问题？
3. 让 AI 改文件之前，为什么要先留下一个可恢复的版本？

看完回到自己的练习目录，完成下方过站任务。**观看视频不代替实际操作，也不增加额外的必做验收。**

## 过站任务（半天）

1. 通读《给代码装一台时光机》——重点记住七个概念里的四个：**commit（存档）、三区域（购物车）、push/pull（快递）、回滚（读档）**
2. 做完讲义末尾的**三件小事**：确认 git 装好（`git --version`）→ 注册 GitHub 账号 → 提交你的第一个 commit（让 AI 手把手带）
3. 把速记卡最后两行读三遍——"AI 时代怎么用：先存档，再放 AI，验收，不行就读档"

## 过站验收

三样齐了就通关：**黑窗口输 `git --version` 能出版本号 ｜ GitHub 能登录自己的账号 ｜ `git log` 里能看到自己的第一个 commit（有你的名字和时间）**。——出发，去第 2 站认识 Godot。
