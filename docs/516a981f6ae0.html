下一条路：AI 原生游戏 —— 当 AI 从工具变成内容

> 课外读物。主线通关后的方向感——你学的 AI 一直是"开发工具"（帮你做游戏）；还有一种正在发生的新形态：AI 当"游戏内容"，游戏里的角色自己会想。

| 为什么值得看 | 你现在做的游戏，NPC 都按写死的剧本走。AI 原生游戏里，NPC 说什么、做什么由大模型实时决定——每个玩家的世界都不一样 |
|---|---|
| **是什么** | 一个开源示范项目 + 通关后的三条路 |
| **怎么看** | 当杂志看，20 分钟；心里冒出"我能不能做个 XX 的 AI 版"就对了 |

my_ai_town：NPC 自己"活"的小镇

| 是什么 | 开源项目（GitHub 搜 `mewamewa/my_ai_town`）：Godot 4.7 + GDScript 的 LLM 驱动像素小镇。居民有性格和记忆，行为由 AI 实时生成 |
|---|---|
| **你已经读得懂它** | 它的 AI 对接层、NPC 的"记忆"怎么存——用你的四大概念和拆解四步法去看，不再是天书 |
| **想跑起来** | 克隆后用 Godot 打开，配置你自己的 LLM API Key（和 Claude Code 同款思路） |
| **看什么** | 别看热闹：看"AI 的回答"是怎么接进信号系统的、"记忆"是什么格式的资源 |

通关后的三条路

1. **打磨发布**：已发布的游戏继续出 v1.1、v1.2——加一个新机制、回应玩家反馈，走完"运营"阶段（参照第 5 站《一个游戏的一生》）
2. **组队做大**：拉同学按示范工程的模式分工（策划/程序/美术），git 仓库共享——做一个人的体量做不出的东西
3. **AI 原生方向**：从 my_ai_town 出发，做"AI 是玩法本身"的游戏——这条路人还很少，天花板很高

> 选哪条都对。重要的是：**你已经完整走过一遍"从想法到玩家"的路**——第二条路只是走得更快更远。
