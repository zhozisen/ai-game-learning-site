# 第2站：认识Godot，从操作走到一个小项目

前置：有独立练习目录，学过Git保存与恢复；能启动教师核对过的Godot版本。不会编程可以开始，但要按主线中的脚本基础逐项练习。

## 今天先做什么

1. 打开01《四大概念卡》，认识节点、场景、信号、资源，不要求背比喻。
2. 打开03《Godot最低开发能力》，按编辑器、场景实例、脚本阅读、输入信号、调试、完整小项目顺序做。每次只做一步。
3. 02《看AI做游戏》与B站视频用于看操作；完整小项目在接星星和官方躲避游戏中选一个，不必重复做两套。

配套视频：https://www.bilibili.com/video/BV1JuCrYcEvJ/
官方文档入口：https://docs.godotengine.org/zh-cn/4.x/
先核对版本选择器，不把不同版本的菜单与API混用。

## 要交什么、做到什么程度

交同一个练习工程和六步观察记录；能重新打开工程、区分场景与实例、解释一段短脚本、检查输入与信号，并修复一个可恢复的小错误。小项目要有开始、核心操作、反馈、结束和重开。可请AI解释，但必须自己运行。教师核对工程，网页概念题与积分只代表对应网页任务。

## 带到下一站

带上一个可以恢复的Git版本及一个尚不清楚的问题；第3站练习如何向AI说清它。不懂语法就回03脚本阅读，不用重看所有视频。第6站还会用这个工程做独立改造。
