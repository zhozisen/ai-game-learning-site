3. 脚本阅读：先跨过最低编程台阶

[官方中文：创建第一个脚本](https://docs.godotengine.org/zh-cn/stable/getting_started/step_by_step/scripting_first_script.html)

[官方稳定版：GDScript参考](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_basics.html)

“第一个脚本”教程默认有一定编程基础。完全零基础的同学先用下面清单逐项练习，再读旋转示例。参考手册只查当前语法，不全文通读；可切换对应版本的中文。AI每次只解释当前几行，让你先预测结果，不要一次生成整款游戏。

| 要能读懂 | 在练习中做什么 |
|---|---|
| 变量与赋值 | 找到速度变量，预测改大后会怎样，修改并运行 |
| 数字、文本、布尔值 | 区分数值计算、提示文字和是否开始的状态 |
| 函数与参数 | 找到一次调用，说明输入什么、执行什么 |
| 条件与缩进 | 判断条件成立和不成立分别会发生什么 |
| 循环 | 在小型列表上观察重复处理，不写无法停止的循环 |
| 节点引用与信号 | 指出脚本挂在哪个节点、事件交给谁处理 |
| 生命周期回调与delta | 区分进入场景的初始化与每帧更新，观察移动速度 |

验收：用自己的话解释一段短脚本，先写预测再改一个参数，核对运行结果。只会背关键字或让AI解释，不等于已会使用。暂不要求理解继承体系、复杂泛型或底层算法。
