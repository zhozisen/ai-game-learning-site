先看全景：两条学习线，合流成八级台阶

学"指挥 AI"有两条线，合在一起就是一条从"会用"到"会设计"的楼梯：

- **概念线（懂它、跟它说话）**：AI 通识概念 → LLM → 提示词 → Agent
- **装备线（给它配装备）**：Harness 设计思维 → MCP → Skill → 插件
- **终点**：Apply（综合应用——做游戏、学一切）

> 为什么是这个顺序？**先懂原理再动手，先会"说话"再学"配装备"**——装备线每一级都是给下一级打地基。

| 级 | 台阶 | 一句话比喻 | 关键词 |
|---|---|---|---|
| 1 | AI 通识概念 / LLM | 读懂"超级笔友"的底牌 | 大语言模型 · 幻觉 · 上下文 |
| 2 | 提示词 Prompt | 把话说清楚，产出才像样 | 四零件：任务+范围+维度+格式 |
| 3 | Agent 工具 | 从"会说话"到"有手" | Claude Code / Codex / Trae / 自定义 |
| 4 | Harness 设计思维 | 给 AI 搭一张工作台 | 手册+护栏+验证+记忆 |
| 5 | MCP | 给 AI 装"万能插座" | 连工具、连数据 |
| 6 | Skill ⭐重点 | 给 AI 一本岗位说明书 | 包内 .claude\skills |
| 7 | 插件 Plugins | 商店里买现成的工具箱 | 装了就能用 |
| 8 | Apply | 把整套本事用到真事上 | 做游戏 · 用 AI 学一切 |

第 1 级 · AI 通识概念与 LLM：懂底牌

**LLM（大语言模型）**= Claude、GPT 们的"大脑"：一个读遍了图书馆、特别会"接话"的超级笔友。它不是"查资料报答案"，而是"一个字一个字接出最像答案的话"——所以它会有**幻觉**（一本正经编造）、**知识截止**（新东西不知道）、**上下文窗口**（聊太长会失忆）。

| 上手动作 |
|---|
| 01 号文档的五组 21 个概念就是 AI 通识总表，本级只补一个新词：LLM。回读 01 号第一组"它是怎么工作的"，练到能对同学讲清"AI 为什么会一本正经地胡说" |

第 2 级 · 提示词：会说话

提示词质量 = 产出上限（概念表已讲）。本级进阶只记一个公式——**好提示词四零件：任务 + 范围 + 维度 + 格式**（01 号过站任务已体会过一次）。

| 上手动作 |
|---|
| 以后每次派活前默念四零件；说不清的，先把话丢给 AI："帮我优化这条提示词：……" |

第 3 级 · Agent：会用"带手的 AI"

Agent = 能自己读写文件、自己跑命令的 AI（概念表第五组"带手的 AI"）。会选工具、会换着用，才算跨过这级：

| 工具 | 是什么 | 对你 |
|---|---|---|
| **Claude Code**（本包主角） | 终端里的全能 AI 员工：有手（读写文件/跑命令）、有技能（.claude\skills）、能装 MCP | 从今天起的主力 |
| **Codex** | OpenAI 家的终端智能体，和 Claude Code 同类思路 | 见识一下：带手的 AI 不止一家 |
| **Trae** | 带图形界面的 AI IDE（中文友好），边看代码边指挥 | 不喜欢黑窗口时的备选 |
| **自定义** | 用 API + MCP 给自己搭专属智能体 | 第 8 级之后的方向，先埋颗种子 |

| 配套视频 | 《10 分钟学会 24 个 ClaudeCode 使用技巧》 https://www.bilibili.com/video/BV1SddcBFESs/ |
|---|---|
| **看完做什么** | 挑 3 个技巧立刻用到自己的知识包上 |

第 4 级 · Harness 设计思维：会搭台

**Harness（挽具/马具）**：拴住马力、让马好好拉车的那套装备。**Harness 设计思维 = 不问"AI 能帮我干什么"，而问"我该给 AI 搭一张什么样的工作台，它才能稳定干活"。**

你已经搭过一个迷你版——**驾驭五件套就是 harness 的雏形**：手册（CLAUDE.md）定规矩、手让它自己干、验证尺定"完成"、护栏防跑偏、记忆攒经验。本级的升级：从"随手用"变成"刻意设计"——开工前先想清楚：规矩写在哪、验证怎么定、工具配哪些、记忆存哪里。这个学生包、老师的工作区，都是照这套思维搭出来的。

| 上手动作 |
|---|
| 把五件套重排成一张"工作台设计图"：四栏——规矩（写什么文件）/ 验证（怎么算完成）/ 工具（配哪些）/ 记忆（存哪里），给你的下一个项目填满 |

第 5 级 · MCP：给 AI 装插座

**MCP（Model Context Protocol）**= AI 界的"USB 接口"：一个统一标准，让任何 AI 都能接上任何工具——查网页、读设计稿、操作表格，插上就能用，不用每个工具单独造一根线。

| 配套视频 | 《Claude Code 从 0 到 1 全攻略》 https://www.bilibili.com/video/BV14rzQB9EJj/ ——看 21:09"安装 MCP Server"和 23:06"用 MCP 还原设计稿"两段 |
|---|---|
| **上手动作** | 让 Claude Code 帮你接一个 MCP 工具，亲眼看它的能力清单长出新的一项 |

> 这部视频同时覆盖第 3~7 级（MCP / SubAgent / Agent Skill / Hook / 上下文管理），建议收藏，按台阶跳着看。

第 6 级 · Skill：给 AI 岗位说明书 ⭐（重点）

**Skill = 教 AI"怎么做某类事"的说明书文件夹。**为什么是全篇重点：提示词说一次管一次，**Skill 写一次管永远**——这是从"AI 用户"变"AI 设计者"的那根杠杆，你和"别人家的 AI"差距最大的就在这。

你早就在用了：包内 `.claude\skills` 里躺着十几个游戏开发技能——`godot-nodes-scenes` 教 AI 规范拼场景、`godot-signals-groups` 教 AI 用对讲机、`godot-gdscript-headless-testing` 教 AI 自己测代码……第 6 站做游戏全靠它们。

| 上手动作（两步） |
|---|
| ① 打开 `.claude\skills\` 任选一个，看它的 SKILL.md——就是一份"专业的事怎么做"的说明书 |
| ② 让 AI 帮你给自己的项目写一个小技能（例如"每次交作业前自查三件事"），存进技能文件夹 |

第 7 级 · 插件 Plugins：买现成的工具箱

**插件 = 官方/社区打包好的能力扩展，市场里装了就能用**（Claude Code、Trae 都有插件生态）。它和 Skill 的分工：

| | Skill | 插件 |
|---|---|---|
| 谁写的 | 你自己（贴合你的事） | 别人做好（通用的事） |
| 像什么 | 你给员工写的岗位说明书 | 商店里买的整套工具箱 |

本级要求"知道、会装"即可，不必急着装。

第 8 级 · Apply：用到真事上

装备全部到位，Apply = 拿真事检验。两个方向：

1. **做游戏**——第 4~7 站全是 Apply：拆真游戏（指挥 AI 动刀）、写 GDD（用它当策划搭档）、第 6 站从灰盒到发布（harness 全开）
2. **用 AI 学一切**——把这套方法论反过来用在学习上：**DeepTutor**（开源 AI 家教） https://github.com/HKUDS/DeepTutor ——把任意 PDF/课本/论文变成深度对话课，AI 讲解、出题、追问到你真懂。体会一下：会指挥 AI 的人，连学习都是加速的
