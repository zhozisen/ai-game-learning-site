# 第6站：从跟练改造走到自己的小游戏

## 开始前

具备第2站实际操作基础、第3站协作方法及第5站一页设计。

## 按这个顺序做

按01分步SOP前进，结合04实践单完成解释、改造、独立任务和试玩修复；03按当前管线查，02背包肉鸽仅为进阶案例，不要求照搬。

## 做到什么程度

交开始—操作—反馈—结束—重开的可玩版本、一次自己组织的功能任务、Git与试玩复验记录。教师核对后去第7站，不能以AI说完成代替运行。

## 卡住怎么办

先停下新增功能，记下版本、具体步骤、预期与实际、报错和尝试方法；只回补相关环节。每次学习留一条记录，改动前保存可恢复版本。外部资料按需，不要求全部读完。
