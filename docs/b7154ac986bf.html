## v2.0.1 - 2026-10-21

修复安装环节三处阻断性缺陷（学生无需任何额外操作，重新双击 02 即可）：

- **双击 02 根本没反应（最致命）**：`02_开始安装.bat` 原为 LF 换行，cmd 会把行拆错——`echo.` 变成 `cho.`、`powershell` 那一行被截断，安装流程压根启动不了。已改为 CRLF，并新增 `.gitattributes` 锁定 `*.bat` 换行，防止再被改回去
- **CC 学生包内部安装脚本同样中招**：其 `双击安装.bat` 也是 LF 换行，会在提权窗口里以同样方式崩掉。安装器现在运行前自动把它转成 CRLF（幂等，已修正则跳过）
- **Godot 装不上**：安装器去 `90_安装源_勿手动动\Godot_v4.7.2\` 找 exe，但安装源里只有 `Godot_v4.7.2.zip`，从不解压——每次安装都提示"未找到 Godot exe，跳过"，桌面没有图标，导读站过站验收永远过不了、第 2 站起寸步难行。现改为第 3 步前自动解压该 zip 到目标目录
- **Watt Toolkit 装不上**：同样只有 zip 没有 exe，现改为第 4 步自动解压后再启动安装
- **装过 Claude Code 的学生拿不到填Key教程**：原来第 1 步检测到已装就整段跳过，03 教程永不出现。现在无论是否跳过，都直接从 CC 压缩包里提取 `AI-INSTALL.md` 补到导读站（只取单文件，不解压整个 277MB 包）
- 所有解压与修正均幂等，失败有中文提示与手动兜底
- 文档同步：04 装备清单注明 Godot 目录由安装器自动解压；01 先读我注明 03 填Key教程跑完 02 才出现
