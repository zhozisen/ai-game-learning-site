# 第4站：先体验，再用工程证据解释

## 开始前

能运行第2站小项目。由教师提供允许学习、规模适合的工程，先拆一个；第二个或大型项目选做。

## 按这个顺序做

打开01，先写玩家目标、选择、反馈、挑战与卡点，再追踪一条场景—信号—数据链；用02整理一份报告。

## 做到什么程度

交自己的实际观察、原因假设、文件/节点依据和验证结果。能解释一次玩家操作如何变成反馈，去第5站。

## 卡住怎么办

先停下新增功能，记下版本、具体步骤、预期与实际、报错和尝试方法；只回补相关环节。每次学习留一条记录，改动前保存可恢复版本。外部资料按需，不要求全部读完。
