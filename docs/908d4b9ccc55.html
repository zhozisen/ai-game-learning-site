# 第3站：把AI协作变成自己能检查的过程

## 开始前

带上第2站工程或一个明确的小问题，不要求先会API、插件与自动化。

## 按这个顺序做

先做03任务卡与一次检查，再做05流程图与一次实践；01用于查概念，02与04属于进阶，不要求把概念表背完。

## 做到什么程度

交目标、必要上下文、实际检查、修改记录和分工流程。能说明AI哪里需要核查，带走一个可复用方法去第4站。

## 卡住怎么办

先停下新增功能，记下版本、具体步骤、预期与实际、报错和尝试方法；只回补相关环节。每次学习留一条记录，改动前保存可恢复版本。外部资料按需，不要求全部读完。
