# 配套样例与模板

由tools/补强教学内容.py中的网页样例生成；示例路径需替换成自己的工程。先看例子，再填自己的成果，不重复交三份作业。

## 上下文与会话交接

### 示例 重开功能交接单（已核对的验证示例）

```text
目标：核对官方躲避小游戏重开后是否恢复初始状态。
环境：Godot 4.7.2.stable.official.ed1daf0bf，GDScript，本地无界面检查。
相关文件：main.tscn、main.gd、player.gd、hud.gd，均已核对存在。
已完成：加载主场景；开始后分数0；方向输入能移动；生成敌人；计分与界面一致；碰撞结束；再次开始归零并清理旧敌人。
证据：官方样例固定提交b761b4cd5718a7118f2c95eb55f181d0a5f004f1，本地teaching_verify.gd九项检查通过。
未完成：图形界面、声音与真人试玩未验证；退出存在资源释放警告。
下一步：在实际图形环境手动连续玩两局，记录重开和结束提示；先复述文件与状态，再决定需不需要修复。
边界：不顺手增加关卡、美术、背包或全局管理器。
恢复依据：保留固定官方来源与本地检查脚本，不覆盖自己的未提交工程。
```

## 任务拆分与依赖

### 示例 一张可验收的重开任务卡

```text
目标：结束后点击重开进入初始状态。
前置：已有结束界面和可运行基线。
输入：实际主场景、分数与初始化脚本。
允许改动：重开按钮事件及本局初始化。
验收：新局分数0；旧临时对象清理；连续三局不重复连接；原移动仍正常。
失败处理：记录差异和错误，保护未提交工作后恢复基线。
依赖：先查现状→按钮触发与初始化一起完成→多局回归。
```

