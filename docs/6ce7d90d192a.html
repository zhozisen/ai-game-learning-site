# 2D美术规范：先让一个资源在游戏里正常显示

这是按需模板，不要求首作具备所有美术管线。先用占位图跑通玩法，再填写当前需要的字段。

## 最小规格表

| 项目 | 自己填写 |
|---|---|
| 用途 | 玩家、道具、背景或按钮 |
| 视觉 | 视角、色板、参考样本与主体比例 |
| 像素尺寸 | 按实际显示大小与目标设备确定，普通2D图片不统一强制2的幂 |
| 格式 | 透明图优先PNG；其他格式按当前引擎支持和质量测试选 |
| 场景比例 | 记录基准分辨率、Sprite2D显示大小与scale；不照搬其他引擎的全局PPU概念 |
| 来源 | 作者/生成工具、许可条件、原始文件位置 |
| 检查 | 透明边缘、清晰度、遮挡、碰撞范围、目标窗口显示 |

先导入一张测试图，验证后再批量制作；压缩、mipmap与过滤设置按目标平台和实测选择，不能只凭文件尺寸判断性能。素材免费不等于无条件使用，AI生成也要核对使用条件。

## 有需要再补

规则精灵表切帧需统一帧尺寸并校准锚点；动画先选最简单可用方案。只有用瓦片地图时才填瓦片规格与拼接需求。按钮可以先用主题、颜色和文字提供状态反馈，不强制画三套图片；可拉伸图片可按需要使用九宫格。多分辨率先测试自己声明支持的窗口与设备，不强迫首作适配所有屏幕。

目录与工程现有命名一致，建议assets/art、assets/audio等简短稳定路径。重命名资源在编辑器中操作并检查引用。交付是一张规格表和引擎内截图，不能只交素材文件。
