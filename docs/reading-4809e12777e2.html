作品申请的三个状态

打开本站「同学作品」，展开「用 AI 发布游戏」，复制提示词。填入自己的 Godot 工程目录和 GitHub 仓库，让 AI 生成可玩的 GitHub Pages 地址。亲自从开始玩到结束重开，再核对申请中的作者、作品名、简介、操作、版本、源码地址和试玩地址。申请预览仍是草稿。

确认正文后，由 AI 使用你已登录的 GitHub 账号代交。如果 AI 无法代交，就用它生成的正文自行提交。拿到 Issue 链接表示已申请。老师试玩后加「通过上架」标签，自动检查通过后，刷新「同学作品」即可看到作品卡。申请是公开的，请只填写展示需要的信息。后续沿用同一试玩网址时，推送游戏新版即可更新试玩内容。
