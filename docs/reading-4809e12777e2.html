作品申请的三个状态

打开本站「同学作品」，展开「用 AI 发布试玩版并提交作品」，复制提示词。填入自己的 Godot 工程目录和 GitHub 仓库，交给能操作工程和 GitHub 的 AI。AI 实测游戏，核对公开展示信息，再发布试玩网页。申请没提交时仍是草稿。

AI 用你已登录的 GitHub 账号代交。拿到 Issue 链接表示已申请。GitHub 自动检查申请账号、仓库归属和网页导出文件，通过后直接展示。如果检查失败，让 AI 根据 Issue 回复修正并编辑原申请。申请会公开，只填写用于展示的信息。同一试玩网址更新游戏时，推送新版并核对部署即可。
