2. MCP：先理解边界，再连接工具

主讲：[通过 MCP 将 Claude Code 连接到工具（官方中文）](https://code.claude.com/docs/zh-CN/mcp)

先读能做什么、查找服务器、安装方式、服务器管理，以及项目批准与信任相关说明。只学习实际需要的一种连接方式；不同平台的安装命令不要混用。

练习：先画清“AI→MCP服务器→资料/工具”的关系。若普通文件读取已足够，记录不需要MCP的原因即可。确有需求时，在练习目录中试一个经教师核对来源、尽量只读的服务，记录它可读哪些数据及如何停用。

交付：连接需求、权限范围、一次成功/失败观察与停用步骤。安装与授权在学生自己的工具中完成；不要把令牌写入网页、公开仓库或报告。不会因为学MCP就自动安装Godot第三方插件。
