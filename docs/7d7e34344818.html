# 装备清单：只准备当前任务需要的工具

先按07总路线表开始。网页可以直接阅读和做概念练习；Godot工程需要在电脑上操作。安装来源与完整版本由教师核对，已有可用环境先验证，不为教程截图随意升级。

| 工具 | 什么时候需要 | 最小自查 |
|---|---|---|
| 独立练习目录 | 导读开始 | 自己能找到、写入、关闭后重新打开；与原资料分开 |
| Git | 第1站 | 能查看版本，提交一次练习改动并恢复一个文件 |
| GitHub账号 | 第1站远程同步时 | 自己登录；账号受限或网络失败找教师，不把密码交给AI |
| Godot与GDScript | 第2站 | 记录完整版本，能保存场景并运行；导出模板到第7站再装 |
| 可用AI助手 | 第3站重点练习，前面可用于答疑 | 能完成一次小任务，知道额度与费用；命令行工具不是先学基本操作的唯一入口 |
| 编辑器/浏览器 | 全程 | 能阅读资料、复制完整报错、保存自己的学习记录 |

Git官方下载：https://git-scm.com/install/windows
GitHub注册：https://docs.github.com/zh/account-and-profile/how-tos/account-management/creating-an-account-on-github

## 本地学生包与进阶工具

教师发放的安装包按配套说明使用；网页不会自动安装这些工具。安装器不存在、版本不一致或需要填写密钥时先找教师核对，不跟随AI猜测下载。密钥由本人通过工具的正规入口配置，不发到公开仓库、问题截图或课堂网页。

Skills、MCP、Hook、加速工具与其他插件均按实际需求选用，不作为起步必装项；技能是否加载须按工具版本和位置验证，不能只因切换目录就声称生效。打不开外站时先做站内练习、记录卡点，再由教师协助。

## 保存什么

网页进度在当前设备浏览器，定期导出备份；工程另用Git与自己的备份保存。能找到文件不等于能恢复，至少实际打开一次备份。把工具启动与测试结果写进记录，未做的检查标未完成。
