# 总路线打卡清单：零基础一步一步完成第一款小游戏

最终目标：做出一款别人能运行、能理解操作、能从开始玩到结束的小型2D游戏，并根据一次真实试玩作出改进决定。首作不要求收费、复杂架构或同时发布多个平台。

## 每次学习怎么走

先看本站先读我 → 领取一个任务 → 按主资料动手 → 解释自己的观察 → 完成工程练习 → 保存证据。网站任务点记录参与，概念题检查部分理解；工程能力另由教师检查，点亮圆圈不等于工程已验收。参考资料只在卡住时查，进阶可全部跳过。

| 顺序 | 主任务和阅读入口 | 本站交付 | 可以继续的依据 | 卡住回哪里 |
|---|---|---|---|---|

## 每站只勾四项

- [ ] 我亲手做过本站任务，保留工程或记录。
- [ ] 我能解释一次操作或改动的原因与结果。
- [ ] 我实际执行了检查，失败的地方已记录并求助。
- [ ] 我知道下一站需要带走什么；需要教师核对的成果已交给教师。

不规定所有人相同天数。每次只完成一个可检查的小任务；不会时允许回补。先完成一个跟练小项目，独立首作沿用学过的功能，避免同时学习新引擎、新平台和复杂玩法。

## 学习与恢复习惯

每次记录：本次目标、实际操作、结果、下一步。改动前保存可恢复版本；不用不理解的删除/覆盖命令。卡住时提供版本、复现步骤、预期/实际、报错与最近修改，先停下叠加功能。教师检查后标记“通过／补做哪项”；网站暂没有教师在线批改系统。

网页进度保存在当前设备浏览器，定期导出备份，换电脑不能自动同步。自己的工程放在独立目录，网站更新不会替你备份工程。带旧版安装器的资料仅适用于本地学生包；网页学习不要求先安装所有选学工具。已有可用环境先验证，不为追求新版本随意升级工程。
