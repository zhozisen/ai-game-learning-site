看 AI 做游戏 —— 第一场演示，边做边讲

| 为什么有这一课 | 概念卡是"背单词"，这一课是"看母语者说话"：让 AI 真的做一个小游戏，边做边解释每一步用了哪个概念。看懂了，四个词才算真的长在脑子里 |
|---|---|
| **跳过会怎样** | 概念卡背得再熟也是纸面的；第一次看 AI 干活时照样懵，不知道它在建什么、改什么 |
| **是什么** | 一次约 30~60 分钟的 AI 演示课：AI 做一个"接星星"小游戏，每步停下来当老师讲解，你看 + 提问 + 最后亲手跑起来 |
| **怎么用** | 照本文三步走：准备 → 让 AI 边做边讲 → 自测 + 亲手跑 |
| **什么时候用** | 第2站按需演示参考，主线按03六步路线执行 |

> 本文是演示方案。可沿用03六步路线中的同一工程，AI每次只实现一小步并等待学生运行验证；不必在学基础前一次生成完整游戏，完整小项目与官方项目二选一。

游戏是什么：接星星

玩家用左右键移动一个小人，天上掉星星，接到得 1 分；漏接 3 颗，游戏结束。
选它当第一个游戏，因为它小而全：**四个概念一个不落**（玩家和星星是场景、每个零件是节点、接到星星发信号、分数和速度是数据）。

第一步：准备（3 分钟）

1. 打开 Claude Code（开始菜单搜 `Claude Code`）
2. 先让它站进知识包：输入 `cd` + 空格，把知识包文件夹拖进窗口（有 `①先点我.txt` 的那一层），回车
3. 建一个练习文件夹：对 AI 说 **"帮我在桌面建一个文件夹：Godot练习"**

> 为什么建在桌面而不是知识包里：知识包以后要收老师的更新，你自己生成的东西放外面，互不打架。

第二步：派活（复制下面整段，粘贴给 AI）

```
我想看你怎么做一个游戏，边做边教我。请用 Godot 4.7 + GDScript 做一个"接星星"2D小游戏：
玩家用左右键移动，天上随机掉星星，接到加1分，漏接3颗游戏结束。
工程建在 桌面\Godot练习\接星星。

规则（很重要）：
1. 分阶段做（搭工程→玩家→星星→计分→结束画面），每做完一个阶段就停下来，
   用初中生能听懂的话解释：你刚才做了什么、用到了四大概念（节点/场景/信号/资源）里的哪一个、为什么用它。
   每个阶段讲完，问我"有没有问题"，我回复"继续"你再做下一个。
2. 全部做完后，给我一张总结表：这个游戏的每个部分对应哪个概念。
3. 最后教我怎么用 Godot 打开这个工程、怎么按 F5 跑起来。
```

这段提示词的关键是**规则 1**：逼着 AI 当老师而不是闷头干。如果它一口气做完不讲，就说："停下，回到上一个阶段，先讲解再继续。"

第三步：看的时候看什么（观察清单）

AI 干活时别干等，对照这张表观察：

| 观察 | 你应该看到 |
|---|---|
| 它建了哪些文件 | `.tscn`（场景）、`.gd`（脚本）、`project.godot`（工程入口） |
| 玩家是什么 | 一个 `.tscn` 场景文件，里面一棵节点树 |
| 接到星星那一刻 | AI 用了**信号**（谁发出、谁监听）——追问它："这里哪个是发信号的，哪个是收的？" |
| 分数、速度这些数字 | 是写死在代码里，还是可以单独改的数据？追问："我想让星星掉快一点，改哪里？" |
| 它什么时候测试 | 好的 AI 会边做边跑检查，而不是全做完才跑 |

**随时提问不丢人**：它的每句话听不懂都可以问"这是什么意思，打个比方"。看 AI 干活时问出来的问题，就是最值钱的学习。

看懂自测（五问，答得出才算看过）

1. 这个游戏里，"玩家"是一个________（四选一：节点 / 场景 / 信号 / 资源）
2. "接到星星加一分"这件事，是谁通知谁的？用的什么机制？
3. 星星为什么可以同一时间出现很多颗而不用写很多遍代码？
4. 如果想让星星下落变快，应该改代码还是改数据？为什么？
5. 用一句话分别说出四个概念（对照 `01_四大概念卡.md` 核对）

亲手 5 分钟（必做，不许跳）

看会了不算会，碰一下才算：

1. 打开 Godot → 导入 → 选 `桌面\Godot练习\接星星` 里的 `project.godot`
2. 按 **F5** 跑起来，玩一局——这是你第一次跑起一个游戏
3. **改一个数**：问 AI "星星下落速度在哪改？"，把数字改大一倍，再按 F5——感受一下"数据"和"代码"的分家
4. 再改回去（或让 AI 帮你恢复）

卡点急救

| 卡点 | 处理 |
|---|---|
| AI 闷头做完不讲解 | 说："停下。回到第一个阶段，一阶段一讲，我回复继续你再做下一个。" |
| AI 讲的我听不懂 | 说："用打比方的方式再讲一遍，我是第一天学 Godot。" |
| 跑不起来 / 报错 | 把报错原样贴给 AI："F5 运行报了这个错，帮我修，修完告诉我刚才错在哪。" |
| AI 一次生成太多 | 说："太多了，拆小，一次只做一个阶段。" |
