第三关：独立组织一次任务

教师只给目标，例如“游戏结束后显示本局成绩，并能重新开始”。学生自己写任务卡、找相关场景/脚本、提出检查标准，再决定怎样用AI。教师不先给完整提示词或答案；卡住先提示相关概念，再给局部示范。独立指自己负责需求、操作和验收，允许查资料、使用AI和求助。

交付：任务卡、改动前后版本、操作证据，以及一个失败或边界情况。口头解释关键输入、状态和事件如何联系；不能只交AI生成的长报告。

卡住的处理顺序

停止加功能 → 保存当前状态 → 确认能否重复 → 读报错的文件和行号 → 比较最近一次改动 → 做最小修复 → 原步骤复验。语法/节点引用回第2站，输入输出不清回第3站，玩法目的不清回第5站。仍解决不了，把版本、复现、预期/实际、完整报错和已尝试方法交给教师。

教师检查：能解释、能运行、能验证则通过；缺哪项就只补哪项。暂没有站内自动工程批改，不把答题和任务点当工程能力证明。
